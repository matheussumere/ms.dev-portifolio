## ⚙️ Modificar Dados

### Para adicionar projeto à galeria
Editar `data.json`:
```json
{
  "id": 7,
  "title": "Seu Projeto",
  "brand": "Marca",
  "service": "Serviço"
}
```

### Para adicionar artigo ao blog
Editar `data.json`:
```json
{
  "id": 4,
  "title": "Novo Artigo",
  "category": "Categoria",
  "content": "Conteúdo"
}
```

### Para adicionar marca
Editar `data.json`:
```json
{
  "name": "Sua Marca",
  "models": ["Modelo 1", "Modelo 2"],
  "specialty": "Especialidade"
}
```
