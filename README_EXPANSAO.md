## 🎓 ESTRUTURA HTML PADRÃO

Todos os projetos seguem este padrão:

```html
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <!-- Meta tags + Schema -->
</head>
<body>
  <!-- NAV (sticky) -->
  <!-- HERO (full viewport) -->
  <!-- ABOUT/INFO -->
  <!-- MAIN CONTENT (3-4 seções) -->
  <!-- GALLERY/PORTFOLIO -->
  <!-- BLOG/ARTICLES -->
  <!-- TESTIMONIALS -->
  <!-- CONTACT/CTA -->
  <!-- FOOTER -->
  <!-- WHATSAPP BTN (fixed) -->
  <script>
    window.WL_CONFIG = { /* config */ }
    fetch('data.json')
  </script>
</body>
</html>
```
